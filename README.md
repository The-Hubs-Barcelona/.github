# .github

Organization-level configuration and defaults for **TheHubs**.

| Path | Purpose |
| --- | --- |
| `profile/README.md` | The public profile page shown on the organization's GitHub landing page. |
| `profile/assets/` | Images used by the profile README. |

Files placed here act as fallbacks for every repository in the organization that does not
define its own (issue templates, contribution guidelines, workflows, and so on).

Edit `profile/README.md` to change what visitors see at the top of the organization page.
