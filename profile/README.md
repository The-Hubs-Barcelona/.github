## What this organization is

TheHubs is our engineering organization on GitHub. Each hub owns its own products,
its own roadmap and its own repositories. **This organization is for everything else** —
the transversal work that belongs to no hub in particular but serves all of them.

If a piece of code, tooling or documentation is useful across hubs, it lives here.
